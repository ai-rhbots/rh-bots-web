¿Qué es el RHD1 Edu?

El RHD1 Edu comparte la plataforma mecánica principal del RHD1 Pro, pero incorpora interfaces, simuladores y acceso de desarrollo para universidades, centros formativos e investigadores.

  • Entorno de desarrollo completo

    Modelo URDF, SDK y compatibilidad con NVIDIA Isaac Sim y MuJoCo para simular antes de desplegar en el robot real.

  • Interfaces de expansión

    Ethernet, USB, salida de alimentación, SBUS y UART para integrar sensores y cargas externas.

  • Misma base mecánica

    Velocidad de hasta 3,7 m/s, 40° de pendiente, salto de 350 mm y 5 kg de carga nominal.

  • Pensado para investigar

    Locomoción, percepción, navegación y aprendizaje por refuerzo.
